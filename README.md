# Advanced Snake Game

An enhanced version of the classic Snake Game built using HTML, CSS, and JavaScript. This project goes beyond the traditional Snake Game by introducing improved gameplay mechanics, a polished user interface, and additional features that create a more engaging experience.

## 🚀 Features

* Smooth snake movement
* Real-time score tracking
* High score system
* shop available
* Power-ups and special items
* Leaderboard system
* different levels
* Sound effects and background music


* Enhanced UI/UX
* Optimized game performance

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## 🎯 How to Play

1. Start the game.
2. Control the snake using the Arrow Keys.
3. Eat food to increase your score.
4. Avoid colliding with the walls or your own body.
5. Try to achieve the highest score possible.
